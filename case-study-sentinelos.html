Case Study: SentinelOS

Problem

Academic environments were storing sensitive student and system data behind weak authentication and inconsistent protection boundaries. SentinelOS addresses that exposure with a modular desktop operating system where identity, encrypted storage, and monitoring are first-class concerns.

Tech Choices

  • JavaScript provides a clear event-driven model for coordinating security telemetry and interface feedback.
  • React enables reusable panels for authentication status, file activity, and monitoring signals.
  • Component boundaries make security-sensitive UI behavior easier to test and reason about independently.
  • A modular service layer keeps storage, authorization, and monitoring responsibilities isolated as the system evolves.

Takeaway

The deepest challenge was parsing a noisy stream of system events into trustworthy behavioral signals without blocking the interface. Careful event normalization and explicit state transitions produced monitoring that remained responsive while preserving an auditable security trail.
