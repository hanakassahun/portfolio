Case Study: FindAddis

Problem

Local businesses in Addis Ababa were difficult to discover online, while residents had no dependable way to search nearby services by category and location. FindAddis turns fragmented local information into a focused, map-driven discovery experience.

Tech Choices

  • JavaScript keeps the search and map experience responsive without forcing full-page reloads.
  • React supports reusable, isolated interface components for business cards, filters, and map results.
  • Node.js and Express provide a lightweight API layer that scales cleanly as listings grow.
  • MongoDB fits evolving business profiles and supports flexible location-focused queries.

Takeaway

The hardest part was synchronizing search state with ArcGIS map state without stale markers or contradictory results. A single, predictable client state flow made every filter, query, and map update resolve from the same source of truth.
